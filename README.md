# kxtroze artist site

Static artist website for kxtroze: Drum & Bass artist, DJ, and producer.

## Structure

- `index.html` - main page
- `css/style.css` - styles
- `js/main.js` - small vanilla JavaScript interactions
- `assets/` - local images, release covers, and NEUROPUNK media

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.
