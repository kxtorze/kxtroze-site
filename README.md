# kxtroze artist site

Ultra-modern artist website for kxtroze: Drum & Bass artist, DJ, and producer.

Built with Astro, GSAP, Lenis, and local media assets.

## Structure

- `src/pages/index.astro` - main page
- `src/styles/global.css` - global visual system
- `src/scripts/main.js` - motion, smooth scroll, lightbox, and canvas noise
- `public/assets/` - local images, release covers, and NEUROPUNK media

## Run locally

Simplest way:

Open `index.html` directly, or double-click `open-site.bat`.

Astro development mode:

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
